# 🌙 Tsukuyomi Novels

Plataforma completa de leitura e estúdio editorial para **Light Novels**, com organização narrativa em múltiplos volumes e interface imersiva.

---

### ✨ Funcionalidades

- **Hierarquia Completa:** Gestão estruturada em Obras → Volumes (com capa e sinopse do arco) → Capítulos.
- **Tipos de Capítulos:** Suporte dedicado para Prólogos, Capítulos Regulares, Epílogos e Histórias Extras (Gaiden).
- **Estúdio Editorial:** Editor integrado com atalhos para diálogos orientais (`「」`, `『』`), quebras de cena e inserção de ilustrações.
- **E-Reader Imersivo:** 
  - 4 temas visuais: Escuro, OLED Black, Sépia e Claro.
  - Ajustes de tipografia, tamanho de fonte e espaçamento.
  - Narração nativa por voz (**Text-to-Speech**).
  - Lightbox em tela cheia para ilustrações.
- **Armazenamento:** Salvamento automático de rascunhos, favoritos e progresso no `localStorage`.

---

### 🚀 Tecnologias

- HTML5 / CSS3 (Tailwind CSS)
- JavaScript Vanilla
- Font Awesome
